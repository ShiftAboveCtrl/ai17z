A small release with one addition the trading research needs.

## The utility runtime reads one exact pool

`market.snapshot` (the current liquidity, price and volume of one exact pool address) is now offered on the utility
runtime, beside `market.resolve_exact`. A token's pool list stops listing a pool once it has been emptied, so a
question about whether the very pool something was bought in is still tradeable has to be asked of that pool by its
address.

Also in this release, from the work since `v1.0.0-beta.86`: `fastify` 5.12.7 for a low-severity header validation
advisory, and the publish and qualify steps of the release pipeline fixed where their first real run found them
wrong (the release name crossing between jobs, the privacy scan's `unzip`, and the package proof reading an owner's
private directories as a stranger).
