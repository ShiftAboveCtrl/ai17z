`v1.0.0-beta.70` answers the question an agent is left with after a wallet or a
network goes quiet: did the transaction I sent happen, and is it safe to send
again? It also fixes a rare Chrome launch that started a browser and then never
found it.

## What happened to a transaction

`transaction.reconcile` takes a chain and a transaction hash, and optionally
what the caller expected: the sender, the recipient, the value and the nonce.
It reads the transaction, its receipt and the head of the chain, and only when
it decides something, the sender's count of mined transactions. It answers
with one of:

- **CONFIRMED**: succeeded and at least as many blocks deep as asked (twelve
  unless the caller says otherwise).
- **CONFIRMING**: succeeded, not yet that deep.
- **REVERTED**: mined and failed; the fee was spent and nothing it asked for
  happened.
- **STATUS_UNKNOWN**: mined, with no status the node will give.
- **PENDING**: seen, not mined.
- **REPLACED**: not found, and the sender has already used that nonce.
- **NOT_FOUND**: the node has no record of it.
- **MISMATCH**: the hash is a different transaction from the one described.

Separately, `mayResend` says whether sending again is safe: **NO** for
anything that happened, may yet happen or is not what was expected;
**YES_AS_A_NEW_DECISION** after a revert; and after a hash nobody has seen,
**ONLY_WITH_SAME_NONCE**, because two transactions with one nonce can never
both execute. A missing transaction is never called a failure: not seen is not
proof it never happened.

It reads only, through the same chain sources as every other chain read, and
every answer names which read came from where. It is on the shared runtime's
capability bridge, so the website and anybody calling the runtime can ask it.

## Chrome's debug port is never one fetch refuses

AI17Z finds the Chrome it starts by asking its debug port, with `fetch`. The
Fetch standard refuses a list of ports before sending anything, 1719, 1720 and
6000 among them, and on a Windows machine whose ephemeral range has been moved
to start at 1024, as Hyper-V and Docker do, a launch could be handed one. Chrome
then started and AI17Z reported it as never having opened its port. The port is
now drawn again until it is one fetch will reach.
