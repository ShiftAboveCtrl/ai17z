## AI17Z moved to GitLab

The project, its releases, its issues and its install command now live on
GitLab. The install command is:

```powershell
irm https://gitlab.com/shiftabovectrl/ai17z/-/raw/main/install.ps1 | iex
```

**An installation from an earlier release will not find this one by itself.**
Its update check asks GitHub, where AI17Z is no longer published. Update it once
by hand, with the command above (it finds and updates the installation that is
already there), or with that installation's own `update-ai17z.ps1 -Package`
pointed at this release's `AI17Z-App-1.0.0-beta.84.zip`. From this version on,
updates are found on GitLab as before.

Everything an installation keeps (agents, memories, credentials, the signed-in
browser) is untouched by the move.

## Downloads come from one place

Every installer and updater now downloads only from `gitlab.com`, where they
used to need four GitHub hosts. The list is shorter and checked the same way:
an address that does not start there is refused, and every file is still checked
against the release's own `SHA256SUMS.txt` before anything is written.

## Provenance you can check

Every published file carries a Sigstore bundle, `<file>.sigstore.json`, signed
by this project's own GitLab pipeline at this release's tag and recorded in
Sigstore's public transparency log. A replaced file cannot carry one. Checking
is optional, needs `cosign`, and is described in
[MACOS_TRUST.md](https://gitlab.com/shiftabovectrl/ai17z/-/blob/main/docs/MACOS_TRUST.md).
It is build provenance, not a signature from Apple, Microsoft or Canonical; AI17Z
is still not code-signed, and says so.

## macOS: Apple silicon only

The macOS package is built for Apple silicon (M1 or newer) and there is no
longer an Intel package: GitLab's Macs are Apple silicon, and an Intel package
built under emulation would be relabelled rather than proved on the hardware it
is for. An Intel Mac already running AI17Z keeps its version, and its updater
says why no newer one is offered.

A release whose macOS package could not be built says so on its release page
and in its manifest, rather than looking like a release that lost a file.

## Upgrading

Nothing to migrate. The one manual update above, once.
