**An empty list was standing in for an answer.** Asked what had been happening in a project it follows, an agent reported that there was nothing to report, about a repository with a hundred and fifty six recorded events. Nothing was broken in the reading. What was missing was a sentence.

## What happened

An agent was asked about the ai17z repository. It reached for the capability that answers out of what AI17Z has recorded, and it had to name a repository, so it guessed one: `ai17z/ai17z`. This agent follows `shiftabovectrl/ai17z`.

The capability answered that correctly. It said it does not follow the name it was given, it named the one it does follow, and it returned no events, because no events matched the question. Every part of that is right.

Then the agent wrote that the events list came back empty. Which is what it had been handed, and is not what it meant.

## Why an empty list is not a measurement

This is the rule the X reading layer states as "absent is never zero", arriving one layer up. There it is about a post whose figures could not be read, which must not reach anything downstream as a post with no engagement. Here it is about a question that matched nothing, which must not reach the model as a project that did nothing.

The difference is that the reader is a model, and what a model acts on is the sentence. So the sentence now says three things instead of one: that the repository is not followed, that nothing in the answer is a count of its activity, and which name would actually answer. The third is the part that makes the other two useful, because a model that knows only what went wrong is correct and still stuck.

Nothing else changed. The lookup was already case-insensitive, already refused to reach another agent's watches, and already answered without calling GitHub. All of that was measured on the installed product before this was written, across all four cases the capability has.

## What holds it

A test that fails without the new sentence, asserting both halves: that the answer disclaims being a count, and that it names the repository to ask for instead. Asserting only the first leaves the defect that actually cost the answer.

## What this release is not

It is not a change to how AI17Z reads a project. It is one sentence and the test that keeps it, and it is here rather than in a note because an agent that reports a busy project as quiet is wrong in front of whoever asked.
