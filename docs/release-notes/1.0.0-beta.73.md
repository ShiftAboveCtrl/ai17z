`v1.0.0-beta.73` moves the tools AI17Z is built with past their published
security advisories. Nothing an agent does changes.

## Build tools past their advisories

Development dependencies only, so nothing an installed copy runs is
different:

- `shell-quote` 1.12.0, past a command injection in `quote()` (critical).
- `source-map-js` 1.2.2, past an event-loop denial of service.
- Both `brace-expansion` lines, past a quadratic-time expansion.

`braces` and `postcss-selector-parser` remain on the versions Tailwind 3
pulls in, because the only fix is the Tailwind 4 major. They run at build
time over this repository's own stylesheets and never see input from
anybody else. The production dependency audit is clean.

## Upgrading

Nothing to do. No migration, no setting.
