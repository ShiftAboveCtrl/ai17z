`v1.0.0-beta.74` lets you see and steer your agents from AI17Z Studio, if you
choose to. It is off until you turn it on.

## Control from Studio

Linked to Studio, an installation used to send only what entitlements need: a
public key, a name, the platform and the version. Nothing about any agent.
That is still the default.

A new switch on the Plugins screen, under AI17Z Studio, **Control from
Studio**, adds two things once you turn it on:

- Studio shows the agents on this machine with what each is doing, in the
  same sentence the agent page shows here, and how many messages wait for you.
- From Studio, on your phone or anywhere else, you can pause or resume one
  agent, or pause and resume everything.

What does not change:

- **This machine always starts the conversation.** About once a minute, on
  the worker's existing sweep, it asks Studio whether anything is waiting.
  Studio never connects to it.
- **Four verbs and no others.** Pause an agent, resume an agent, pause
  everything, resume everything. Nothing typed in Studio becomes something an
  agent says or reads.
- **Resuming runs the same checks as the Start button**, and if something is
  missing the reason is what Studio shows.
- **Nothing else is sent.** No memory, prompt, draft, account handle,
  provider key or browser session.
- A command older than fifteen minutes is not carried out, and one Studio
  sends twice is carried out once.

Turning the switch off tells Studio once, withdraws anything still waiting,
and stops sending anything about your agents.

## Uniswap v4 pools have a history

`market.new_pools` lists Uniswap v4 pools, which are named by a 32-byte id
rather than an address, and on Base that is most of them. `market.ohlcv`
and the pool snapshot accepted only a 20-byte address, so the history of a
pool discovery had just listed was refused. Both now take a pool id.

## Upgrading

Nothing to do. No migration. The switch starts off.
