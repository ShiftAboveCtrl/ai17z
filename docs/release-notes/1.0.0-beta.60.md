**A hardening release: a second installation stays second, and an empty X read says what it really is.** No new features.

## Several installations on one machine

- **Updating one installation no longer makes it the primary one.** On a machine with two installations, updating the second used to make it the one the classic installer offered by default, and the one its uninstaller offered to delete. Now only the first installation, or one you choose with `-MakePrimary`, is the primary one.
- **The classic uninstaller offers the data of the installation you are removing**, never another one's.
- **A new installation is never offered another installation's data folder.**

## Reading X

- **An empty result says which kind of empty it is.** X's error screen, a timeline that never loaded, a different profile than the one asked for, and an account that has genuinely never posted no longer look the same. Only the last is treated as empty.
- **Research waits instead of guessing.** If X will not show an account's posts, Agent Foundry tries again later, a bounded number of times, and then says so. It proposes nothing built on a failed read.
- **Replies inside conversations are read**, and only the account's own words count as its voice: the posts they reply to and the posts they quote are context, never their writing.
