AI17Z is a local-first platform for running autonomous agents on your own machine. An agent is an identity, a memory, a model, a policy, and a set of channels it can act on.

## An imported agent could not be started

Importing an agent produced one that looked complete — its character, its memories, its models, all there — and then refused to start:

> This agent has no pipeline. Reopen the agent page, which creates one.

Reopening the agent page creates nothing. Nothing on that path ever did. So the software gave an instruction that could not work, on the one screen where you had done everything right.

The cause: a package deliberately carries no pipeline. The graph is stock, and shipping one would import somebody else's wiring along with their character — so the stock one has to be created on arrival, and was not. Every other way of making an agent already did this: creating one, duplicating one, importing from AI4CZ, even the test fixtures. Import was the only path that missed it.

Three things changed, because it was three faults:

- **Import creates the stock pipeline.** The actual hole.
- **Starting repairs an agent that is already in this state**, so an agent you have already imported fixes itself the first time you press Start. Nothing to re-import, and nothing is lost.
- **The message no longer gives an instruction that does nothing.** If it appears now, creating the pipeline genuinely failed, and it says that is a fault in AI17Z rather than something you missed.

**If you already have an imported agent that will not start:** update, open it, and press Start. That is all.

## Everything from Beta 1.0.0 (4)

**Typing works.** Typing one character into any field inside a dialog moved the caret out of it, so you had to click the field again for every character. It affected every form in every dialog. Fixed and measured: eight keystrokes out of eight lost the caret before, none out of thirteen after.

**The model is a list**, with a button to fetch what the provider offers, and free text still available for a model too new to be listed.

**Paste your key and AI17Z works out whose it is** — Claude, OpenRouter, xAI, Gemini. Always a suggestion, always overridable.

**Google Gemini is supported.** It was missing while every other provider was present.

**The provider dropdown explains itself** rather than reading as though one key is all AI17Z has.

## Updating

Nothing updates itself. AI17Z asks GitHub what has been released at most once every six hours, shows you the notes, and offers a link. You can ignore it, skip a version permanently, or turn the check off entirely.

Run this installer over the top of an earlier one. Your agents, memories, provider keys and settings live in your data folder and are not touched. The first start after an upgrade rebuilds and says so.

## Verifying the download

```powershell
Get-FileHash .\AI17Z-Setup-1.0.0-beta.5.exe -Algorithm SHA256
```

Compare against `SHA256SUMS.txt`. The installer is not code-signed yet, so Windows SmartScreen will warn about an unknown publisher.

## Known limits

- **Windows is the verified platform.** The Linux scripts are written and syntax-checked, but nobody has taken a clean Ubuntu machine through the flow.
- **Headless servers are not a supported flow.** Connecting an X account opens a real Chrome window for a person to sign in to.
- **One X account has been run end to end.** Two agents in one installation and two installations on one machine are both tested; two signed-in X accounts side by side are not.

## Requirements

Windows 11, Docker Desktop, Node.js 20+, and Google Chrome. The installer detects what is missing and tells you; it does not bundle them.
