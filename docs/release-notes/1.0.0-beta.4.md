AI17Z is a local-first platform for running autonomous agents on your own machine. An agent is an identity, a memory, a model, a policy, and a set of channels it can act on.

This release fixes a bug that made the interface genuinely unpleasant to use, and rebuilds how you choose a provider and a model.

## Typing works

Typing one character into any field inside a dialog moved the caret out of it. The next character went nowhere, the dialog took the selection, and you had to click the field again — for every character. Entering a model name was the worst of it, but it applied to every form in every dialog: renaming an agent, adding a provider, editing a model, all of it.

The dialog focused itself at the end of an effect that re-ran on every render, and typing causes a render.

Fixed, and measured rather than assumed: typing into the model editor lost the caret on eight keystrokes out of eight before, and none out of thirteen after. A probe then typed into every visible field on every screen — the character sheet, behaviour, memory, settings, setup, and each dialog — and found nothing else. It was one cause, in the one component every dialog is built from.

## Choosing a model

**The model is a list now.** It was a free-text box with a hidden suggestion list attached, which showed nothing until you clicked a control most people never find, and never told you whether what you typed was real. Getting it wrong fails every generation.

- Pick from what the provider offers.
- **Fetch the list from the provider** asks it directly and remembers the answer.
- **Type a model name instead** is always there, because a model released this morning is not in any provider's list yet.

## Choosing a provider

**Paste your key and AI17Z works out whose it is.** The form used to ask which provider first, from a list of internal names like `openai_compatible`. Now the key comes first: `sk-ant-` is Claude, `sk-or-` is OpenRouter, `xai-` is xAI, `AIza…` is Gemini. A plain `sk-` is reported as a guess rather than a fact, because many services copied that shape, and a key with no recognisable prefix produces no guess at all instead of a wrong one. It is always a suggestion — choosing by hand stops it, and every provider stays selectable.

**Google Gemini is supported.** It was missing while OpenAI, Claude, OpenRouter, DeepSeek, xAI and Ollama were all present. Added through Google's OpenAI-compatible endpoint.

**The provider list explains itself.** The dropdown when configuring a model shows the keys *you* have added — which, with one key, read as "this is the only provider AI17Z has". It now names the others and links to where you add one. The picker also shows real names rather than internal identifiers.

## Updating

Nothing updates itself. AI17Z asks GitHub what has been released at most once every six hours, shows you the notes, and offers a link. You can ignore it, skip a version permanently, or turn the check off entirely.

Run this installer over the top of an earlier one. Your agents, memories, provider keys and settings live in your data folder and are not touched. The first start after an upgrade rebuilds and says so; that takes a few minutes and only happens when the code has actually changed.

## Verifying the download

```powershell
Get-FileHash .\AI17Z-Setup-1.0.0-beta.4.exe -Algorithm SHA256
```

Compare against `SHA256SUMS.txt`. The installer is not code-signed yet, so Windows SmartScreen will warn about an unknown publisher.

## Known limits

- **Windows is the verified platform.** The Linux scripts are written and syntax-checked, but nobody has taken a clean Ubuntu machine through the flow.
- **Headless servers are not a supported flow.** Connecting an X account opens a real Chrome window for a person to sign in to.
- **One X account has been run end to end.** Two agents in one installation and two installations on one machine are both tested; two signed-in X accounts side by side are not.

## Requirements

Windows 11, Docker Desktop, Node.js 20+, and Google Chrome. The installer detects what is missing and tells you; it does not bundle them.
