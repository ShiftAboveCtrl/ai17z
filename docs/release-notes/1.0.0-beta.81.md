`v1.0.0-beta.81` lets an agent's wallet say which tokens it holds.

## What a Solana wallet holds

AI17Z could read a Solana wallet's SOL and nothing else, so an agent that
had bought a memecoin could not show it.
`solana.read_token_holdings` now lists every token a wallet holds a balance
of:

- **Both token programs**, the original and Token-2022. A read of only one
  misses the other entirely.
- **By mint and exact amount**, never a ticker: anybody can create a token
  called anything. Amounts are exact, and ordered without rounding.
- **Empty token accounts** are counted and left out. A wallet with hundreds
  of tokens shows the largest hundred and says that it did.
- **An answer that is not a list is an error, not an empty wallet**.

It is a read-only question asked by the wallet's owner address, answered
from the node's own index of accounts by owner, and it can move nothing.
It is available to an agent and to a linked AI17Z Studio.

## Upgrading

Nothing to do. No migration.
