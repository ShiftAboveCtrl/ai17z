Beta 0.96 lets an evidence card point to the Studio check page and gives an agent's public home a pitch the owner approves.

## What changed since Beta 0.95

**An evidence card can end with a link to the Studio check page.** It is off by default (`tools.evidenceCardLink`). The link is built only from a linked Studio origin and the mint the token check actually read. A card that runs too long drops the link, and a stale or forged link is held for review. The validator exempts only that exact runtime-built `Full check:` line from the address guard. A check link the model wrote itself, the same mint on another line, or any other address is still held as an unverified address.

**The public home has a pitch and a share card.** Owners can give the agent's public home a one-line pitch. The post that shares the home link carries that pitch with a fixed disclosure that any trading results shown are simulated paper results. The pitch is refused when it is saved if it touches a subject the agent stays quiet about, claims an identity, predicts a price or claims a performance. Nothing is posted until a pitch is saved, and the panel says so. Studio serves the link preview itself, so this release carries no title or image. This adds migration 0134, one nullable column.

## Known limits

Studio has already been updated to receive the pitch. The check link and the share post have been exercised against mocks and a test database, not against live X.

## Upgrading

Use the updater belonging to the installation you want to update. Beta 0.96 uses the semver tag `v1.0.0-beta.96`. GitHub Actions builds the Windows, Ubuntu and macOS packages and verifies the published release files.
