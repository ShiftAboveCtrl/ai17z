AI17Z is a local-first platform for running autonomous agents on your own machine. An agent is an identity, a memory, a model, a policy, and a set of channels it can act on.

## A silent install obeyed a radio button nobody could see

Beta 1.0.0 (14) added `/INSTANCE=` so that a silent install could say which of several AI17Z installations it means, and said it worked. It did not, and this release is mostly that correction.

Running `AI17Z-Setup.exe /VERYSILENT /INSTANCE=AI17Z-test` on a machine with more than one installation named the new installation correctly — its entry in Add/Remove Programs, its Start Menu group, its desktop icon — and then put the files somewhere else: into whichever installation happened to be found first. That leaves an installation named one thing and living inside another, with an uninstaller registered to delete a program directory belonging to something else.

The cause is that a silent install still runs the whole wizard, without showing it. The page that lists installations it found was still being visited, its first entry was still selected by default, and selecting an entry is supposed to point the rest of the wizard at that installation — so it moved the folder after the command line had already settled it. The folder is now left alone whenever a name was given, and the pages that would ask a question the command line already answered are skipped.

**If you only ever run the installer by double-clicking it, none of this affected you**, in Beta 1.0.0 (14) or before. Without `/INSTANCE=` the name and the folder come from the same choice and agree.

This was found by running the published Beta 1.0.0 (14) installer, not by reading it. Every static check of that code passed.

## Everything from Beta 1.0.0 (14)

**Fifty-six things your agent can reach for while it is answering**, in five groups, with one screen where you decide which of the sixty-eight it may touch. Contracts, balances and transactions across seven EVM chains, plus Solana and Bitcoin on their own terms. Token prices and where the depth actually is. Value locked, and stablecoin supply chain by chain. DAO votes, at the block the voting power was measured at. What security services have observed about a token or an address — observations, never a verdict. Reference works. Scholarly papers by DOI or arXiv id, with retractions and corrections on record. Structured entity facts that keep the ambiguity rather than guessing. Archived pages, always reported with the date they were captured. Feeds read on demand. SEC filings, once you have set `AI17Z_SEC_CONTACT` to the address the SEC should use to reach you.

**Turning a group on means each capability's own default** — reading allowed, anything that writes still off or still asking. Nothing is on unless you turn it on, and an agent with every group off still generates, remembers and acts, and reaches nothing while doing it.

**Every installed copy has been reporting the wrong build** since before Beta 11. Fixed.

**Exporting an agent no longer drops what it may reach for.**

## Updating

Nothing updates itself. AI17Z asks GitHub what has been released at most once every six hours, shows you the notes, and offers a link. You can ignore it, skip a version permanently, or turn the check off entirely.

Run this installer over the top of an earlier one. Your agents, memories, provider keys and settings live in your data folder and are not touched. The first start after an upgrade rebuilds and says so.
