AI17Z is a local-first platform for running autonomous agents on your own machine. An agent is an identity, a memory, a model, a policy, and a set of channels it can act on.

## Installing is now one command

Open **Windows Terminal** and paste this:

```powershell
irm https://raw.githubusercontent.com/ShiftAboveCtrl/ai17z/main/install.ps1 | iex
```

That is the whole installation. There is no download, nothing to double-click, and **no AI17Z executable is involved at any point**.

This is the first release that supports it. Every release before this one carries an installer you download and run instead, and the command above will say so rather than pretending otherwise.

## Why it changed

AI17Z is not a signed application. Code signing for open-source projects is granted on the strength of an existing user base, and AI17Z does not have one yet — we applied, and were turned down for exactly that reason.

An unsigned `.exe` that Windows has never seen produces a warning, and Windows is right to produce it. The answer to that is not to talk you past the warning; it is to stop asking for one. **Nothing here disables, excludes or reconfigures SmartScreen, Smart App Control, Defender or your execution policy**, and nothing needs to: Windows' default policy permits individual commands and refuses script *files*, so what runs is read and executed as a command rather than launched as a script.

Your execution policy is not changed, and you are never asked to change it.

## What actually runs

[`install.ps1`](https://github.com/ShiftAboveCtrl/ai17z/blob/main/install.ps1) is around 200 lines of code under a long comment explaining itself. It is the file at the URL you just pasted, and you can read it there before pasting anything.

All it does is ask GitHub for the newest release, download that release's setup program, **check its SHA-256 against the hash the release published**, write it somewhere you can read it, and run the bytes it checked. A mismatch stops everything, and there is no flag to skip the check.

The setup program then downloads one file — the application itself — and checks that against the same published hashes before extracting a byte of it.

## Git is not required

A normal Windows installation needs no Git, and never did anything with a repository: the application arrives as a release package that is downloaded and hash-checked, not cloned. This release proves it rather than asserting it — the clean-room harness now installs, starts, migrates, signs in and stops with Git removed from `PATH` entirely.

Git is still what a *source checkout* updates with. That is a different thing, for people working on AI17Z.

## What it installs, and what it leaves alone

**WSL 2**, **Docker Desktop**, **Node.js 22 or newer** and **Google Chrome** — only the ones you do not already have. WSL comes from Microsoft's own `wsl --install`, and the rest from **winget**, Microsoft's package manager. AI17Z never downloads an executable from a link of its own.

Anything already present and new enough is left exactly as it is.

**Docker has to actually answer before AI17Z carries on.** Installed, running and healthy are three different states, and the old advice — "install Docker, restart, run the installer again" — existed because only the first was ever checked. Setup now waits for the engine on a bounded timer, and when Docker is sitting on its own first-run terms it says so in plain English and stops. **AI17Z never accepts a vendor's agreement on your behalf.**

You will see **one** Windows administrator prompt, for WSL 2 and Docker Desktop, explained on screen before it appears. Chrome and Node install per user and need no prompt at all.

If Windows asks for a restart after turning on WSL, setup saves where it got to and leaves **Continue AI17Z Setup** in your Start Menu. Open it afterwards and setup carries on, re-checking everything rather than trusting what it wrote down. That shortcut is deleted when setup finishes: there is no service, no scheduled task and no Run key.

## More than one AI17Z, and updating just one

A machine can hold several independent installations — different agents, different databases, different signed-in accounts. They share nothing, and **updating one leaves every other one exactly as it is.**

```powershell
$s = irm https://raw.githubusercontent.com/ShiftAboveCtrl/ai17z/main/install.ps1
& ([scriptblock]::Create($s)) -List                 # what is installed
& ([scriptblock]::Create($s)) -NewInstance          # install another
& ([scriptblock]::Create($s)) -Instance AI17Z-test  # act on that one
```

Run the plain command on a machine that already has AI17Z and it **asks** which you meant. With several installed and nobody there to answer, it stops and tells you how to name one. It never picks for you, because picking wrong means replacing an installation you did not ask it to touch.

An update updates the installation it was started from and no other. *Update AI17Z* in the Start Menu belongs to one installation, the update screen in the application belongs to the copy serving it, and both refuse a request naming a different one.

This is checked by installing three, updating the middle one, and comparing the other two file by file — 4,778 files each, byte for byte.

## Verifying what you ran

Every asset on this page has a line in `SHA256SUMS.txt`. The setup program is written to `%LOCALAPPDATA%\AI17Z-setup` before it runs, kept there whenever anything goes wrong, and removed after a clean run — pass `-KeepDownload` to keep it either way.

**Install AI17Z only with the command published by the official repository**, <https://github.com/ShiftAboveCtrl/ai17z>. Nowhere else distributes it.

What a hash does and does not protect against, and the one step in the chain that is not pinned, are set out in full in [SETUP_AUDIT.md](https://github.com/ShiftAboveCtrl/ai17z/blob/main/docs/SETUP_AUDIT.md).

## The older installer

`AI17Z-Setup-<version>.exe` is still built and still published. It is **unsigned, labelled as such, and not the recommended route** — it exists because installations made with it update by running a newer one. If you run it Windows will warn you that it does not know the publisher, and that is correct. Use the command instead.

## Updating

Nothing updates itself. AI17Z asks GitHub what has been released at most once every six hours, shows you the notes, and waits. You can ignore it, skip a version permanently, or turn the check off entirely — off means no request is made at all.

Your agents, memories, provider keys and browser sessions live in your data folder and are never touched by an update.
