**Everything in Beta 3.5, and the two things a paired Telegram bot would have got wrong on its first morning.** Both were found by asking what an installation that already has a bot connected would see when it takes the update, rather than what a fresh one would.

If you have not connected Telegram, this release changes nothing for you and Beta 3.5's notes are the ones to read.

## A command you typed hours ago is not an instruction now

Telegram holds unread messages for a day, and the bot only ever acknowledged what it read while pairing. So the first time an installation with a connected bot takes a release that reads commands, it finds everything typed at that bot since the day it was paired.

Anything older than fifteen minutes is now acknowledged and left alone, so it is never seen again, and answered with a sentence saying why nothing happened. Silence would read as the bot being broken.

This is the rule AI17Z already applies to a post it finds late: widening what something is triggered by changes what happens next, never what happened yesterday.

## The button Telegram puts on every bot does not change anything

`/start` is the button Telegram shows the first time you open a chat with a bot, and the conventional first thing anybody types. It meant "lift the pause", which is exactly the wrong thing for a message that could be sitting unread from the day you set the bot up.

It means "here is what I can do" now.

`/stop` is gone for the mirror of that reason. In Telegram it conventionally means "stop messaging me", and it would have stopped every agent instead. Typing it gets you the list, which names `/pause` and `/mute` and lets you say which you meant.

## Who else can drive your bot

The chat is what identifies you, so anyone who can write in it can use these commands. If you paired a group, everybody in that group can pause your agents and decide what they send.

That is a reasonable thing to want and an unreasonable thing to find out by accident, so the settings screen says it where you are choosing which chat to pair.
