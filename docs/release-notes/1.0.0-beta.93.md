Beta 0.93 teaches posting to tell the difference between a post that was sent and a post that was seen. It also lets a post carry an image or a video, and lets the agent decide when media is worth including.

## What changed since Beta 0.92

**A post counts as published only when it can be read back.** An action is marked executed only when the post is found on the channel afterwards. If the check cannot confirm it, the post is held for the owner instead of being reported as sent or sent again. A post found stale and in flight is held unless the channel proves it is absent, the unconfirmed-post notice is resolved once the post is confirmed, and a held post is never retried automatically.

**Posts can carry an image or a video.** A scheduled or owner post can attach media. What a file is comes from its own bytes, never from its filename or content type, and the file is checked again just before the post goes out. A post with media counts as published only when the read-back shows the media on the post; otherwise it is held and the owner is told. The development updates sender and its assistant tool accept attachments, and previews, cleanup and recovery were tightened after review. The first release of this adds migration 0129.

**The agent decides, post by post, whether media helps.** Each decision is recorded with its reason, once per job, and can be inspected afterwards (migrations 0130 and 0131). A screenshot of a live page is taken only for a link the owner wrote, on a host the owner listed. That list is empty by default, so nothing is captured until someone adds a host to the policy; there is no screen for it yet. Capture runs in a separate background browser context with no cookies and checks the address it actually reached. An optional creative provider hook exists as a Plugin feature and is off by default. With it off, behaviour is the same as before and no trace is written.

**The Forgejo backup sync no longer needs a GitHub credential.** It reads the public repository anonymously and downloads release files from the public release address. A credential is still honoured if one is set. Trust is unchanged: the checksum file and the cosign check remain mandatory.

## Known limits

The upload selectors for media on X have been exercised against mocks only, not against x.com. Screenshot capture has been run against mocks, not against real Chrome. A media post recovered from an interrupted run is held for the owner until the channel can report that its media was confirmed.

## Upgrading

Use the updater belonging to the installation you want to update. Beta 0.93 uses the semver tag `v1.0.0-beta.93`. GitHub Actions builds the Windows, Ubuntu and macOS packages and verifies the published release files.
