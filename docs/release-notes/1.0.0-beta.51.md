**Your agent now rests, keeps a budget, remembers who asked to be left alone, and learns which suggestions you keep turning down.** Six controls, all of them ceilings rather than goals, and none of them touching what happens when somebody writes to your agent.

## The shape this is aiming at

Watch a lot. Reject nearly all of it for nothing. Think hard about one or two. Act rarely. Rest.

The release before this one stopped watched keywords from costing a full reply each. What it did not do was put any limit on the activity as a whole: how often the agent went looking, for how long, or what it could spend while it was there. That is what this adds.

## Quiet hours

Your agent now has eight continuous hours a day when it does not go looking for anybody. Eleven at night to seven in the morning by default, in the timezone you set.

An account that approaches strangers at four in the morning reads as a machine to everyone who sees the timestamp, and there is nothing to gain from the hours when nobody is awake.

**This does not touch answering people.** A mention arriving at three in the morning is still found and still answered.

## Sessions, cooldowns and budgets

Going looking now happens in sessions with a beginning and an end, rather than continuously:

| | Default |
| --- | --- |
| Sessions a day | 8 |
| How long one lasts | 15 minutes |
| Rest in between | 45 minutes |
| Candidates thought hard about per session | 2 |
| Optional model calls | 4 a session, 24 a day |
| Things looked up on the web | 2 a session, 8 a day |
| Posts of its own | 3 a day |
| Reposts | 2 a day |
| Automated likes | **0** |
| Automated follows | **0** |
| Unsolicited direct messages | **0** |

The last three are zero deliberately. Automated likes at scale are a bot signature whatever else an account does; follow churn is the oldest growth trick there is and everybody recognises it; and an unsolicited message lands in somebody's private inbox. Each is a number rather than a switch, so you can allow some if you want, but none is the default.

Every one of these is a **ceiling**. Nothing tries to use what is left, and an agent that has spent none of its allowance is behaving correctly.

The budgets are counted from what actually happened rather than from a running tally in memory, so restarting, upgrading or a crash does not hand your agent a fresh allowance. An agent that has used its day has used its day.

## Somebody who asks to be left alone

If a person tells your agent to stop replying, stop tagging them, or leave them alone, that is now recorded permanently and your agent will not approach them again.

It survives restarts and upgrades, because a request that lasts until the next deployment has not been honoured, it has been waited out.

The decision is made by reading the words, not by asking a model. That keeps it something you can check and correct: the panel shows who asked, when, and the sentence they actually wrote. Phrases that only look like a request are deliberately left alone, so "don't stop, this is great" and "I couldn't stop laughing" do not silence anybody.

If you decide somebody should be contacted again, there is a button for it. The original record is kept rather than deleted, so months later you can still see that they once asked.

## What your decisions teach it

When you approve or turn down a suggestion, your agent now remembers the *kind* of suggestion rather than the individual one.

Turning something down means substantially the same proposal will not come back for seven days, unless something real about it changes: a new message from that person, a different target, different content, or a setting you altered. Time passing is not a change.

Approving things of a kind moves similar ones higher up your list.

**This changes the order you are shown things, and nothing else.** It can never grant a permission, skip an approval, widen what a Plugin may do, or turn a proposal into an action. Those live elsewhere and this cannot reach them. The signals also fade, so one good week does not decide next year.

## When the account is struggling

Your agent now tracks how the account is coping, separately from whether it is signed in.

If X starts asking it to slow down repeatedly, or writes keep failing, it stops going looking for people first. If it gets worse, it stops speaking publicly. Reading what people sent you is the last thing to stop, because an agent that stops noticing mentions to protect itself has stopped being an agent.

If X asks for a security code or the session stops being accepted, that needs you, and the panel says so plainly rather than showing a colour.

One case is treated more seriously than any amount of ordinary failure: an action that finished without AI17Z being able to tell whether it went out. Nothing is retried until that has been checked, because retrying one of those is how the same thing gets posted twice.

## Where to find all of it

Behaviour → **What it does unasked**, on the agent's own page. Current state, why it is resting if it is, what it has spent today, the account's health with the reason in words, and the list of people who asked to be left alone.

## Nothing changed for existing agents except the limits

Going looking stays on if it was on. What changes is that there is now a ceiling on it where there was none. No agent will do more after this upgrade than it did before.
