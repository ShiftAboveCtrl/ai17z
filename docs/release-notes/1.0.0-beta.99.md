Beta 0.99 turns on the capability loop for newly created agents, with read-only tools only.

## What changed since Beta 0.98

**New agents can use their read-only capabilities out of the box.** An agent created from Beta 0.99 on starts with the capability loop on, so it can call the tools it has been allowed to read with, such as looking up its own status, without the owner having to find the setting first.

- Only read-only capabilities start enabled. Every capability that can write or act starts disabled, and the owner turns each one on deliberately from the Plugins screen.
- An owner who supplies their own policy when creating an agent keeps it: an explicit capability loop choice, on or off, is stored exactly as given, and so is an explicit tool allowlist.
- Existing agents are untouched. Stored policies, imported agents and Easy Mode saves keep the capability loop setting they already have, and no migration changes any agent.

This release adds no migrations.

## Known limits

Agents created before Beta 0.99 keep the loop off until their owner turns it on. Enabling a write capability still takes an explicit owner decision per capability.

## Upgrading

Use the updater belonging to the installation you want to update. Beta 0.99 uses the semver tag `v1.0.0-beta.99`. GitHub Actions builds the Windows, Ubuntu and macOS packages and verifies the published release files.
