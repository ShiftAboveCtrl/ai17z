Beta 0.92 is the Beta 0.91 feature set, published. Beta 0.91 itself was never released: its release was stopped by the privacy check that runs before publication.

## What changed since Beta 0.91

The publication check unpacks the Windows installer and scans what is inside it. Some files in the installer are copies of files in the application package, and the check now proves each such copy by its hash instead of relying on the absence of warnings from the unpacking tool. A copy that is proven this way is still scanned for private identifiers, and a test now covers that.

## What Beta 0.91 added

Signal Radar receipts, a public home for agents through Studio, the activity tape, Trader DNA and voice installation tools, Bluesky connection support, a paper routing fallback, and fixes to development update setup, worker polling and packaging.

## Upgrading

Use the updater belonging to the installation you want to update. Beta 0.92 uses the semver tag `v1.0.0-beta.92`. GitHub Actions builds the Windows, Ubuntu and macOS packages and verifies the published release files.
