**You can now build an agent from research, talk to your agents, ask them about themselves, and see at a glance what needs fixing.** Everything here builds on the agent you already have: nothing is copied, and nothing changes an agent unless you accept it.

## Agent Foundry

- **Start from a brief.** Describe the agent (whose voice, which projects, how active) and AI17Z researches it: the account's public posts and replies on X, official sites, documentation and repositories. Progress shows each stage as it happens, and the research runs on the worker so you can leave the page.
- **Every proposal shows its evidence.** Voice, topics, beliefs, knowledge, safety rules, Social Radar sources and capabilities each come with what they rest on, how sure AI17Z is, and what is there now: already correct, missing, weak, stale or contradictory. Accept, edit or reject one item, a section, or everything, then apply.
- **Improving an existing agent never applies anything by itself.** It proposes, and keeps your own choices (a pinned belief, your wording) where the evidence agrees with them.
- **Test this agent.** The Foundry writes the situations that go wrong for this setup (a confident wrong claim, a fake announcement, a live price, a scam contract, a hostile message, an identity question and more) and runs each through the real pipeline as a rehearsal. Nothing is sent. Each comes back passed, stayed silent, failed, or for you to read, with the answer it would have given.
- **Third-party X mirrors are optional and never forced.** TwStalker and Sotwe currently challenge automated visitors, so AI17Z marks them unavailable and carries on without them. Nothing tries to get past a challenge.

## Knowledge collections

- **Documentation sites and GitHub repositories** can now be knowledge sources: read within fixed limits, refreshed page by page, with version labels so a question about V2 is not answered from V1 without saying so. A read that did not finish never removes anything.

## Chat

- **Talk to your agents** from the new Chat entry: one at a time, or up to four together in a room. It is the real agent, with its own memory, beliefs and voice.
- **Ask it about itself.** "What's broken?", "What did you do this week?", "What are you learning?", "Why didn't you answer this?" are answered from what AI17Z actually recorded, and it says plainly when something was not recorded. None of this is available to anybody but you.
- **See what an answer used.** Each answer can show the records it read, the memories it was given, what it looked up and which model wrote it.
- **Conversations are not memory.** Only what you save with Remember this is kept, by the agents you choose.
- **Rooms stay in their lanes.** Each agent answers with only its own memory, and answers never set off more answers.

## Setup and health

- **Every agent's Overview opens with concrete checks** and a link to the exact setting that fixes each one: a persona source that has not refreshed, knowledge that failed to read, a subject it talks about with nothing official to read on it, Social Radar sources that are failing, replies waiting for you. Not set up is shown quietly and is never called a fault.
- **Find any setting by typing what it is called:** Ctrl+K, or the search button. Social Radar, beliefs, knowledge, responses, learning, browser and policies each take you straight there.
- **Learning shows its working:** how many measured replies a change has with and without it, when it will be decided, the one decision in five kept as a control, and the things it can never change.
