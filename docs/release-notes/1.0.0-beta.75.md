`v1.0.0-beta.75` lets you watch an agent's browser from AI17Z Studio. It is
off until you turn it on, and nothing can be typed into the browser from
Studio.

## Live view in Studio

A new switch on the Plugins screen, under AI17Z Studio, beside Control from
Studio. With both on, an agent's page on Studio has a Browser tab with a
Watch button, and you see the real browser on this machine, about one
picture a second.

- **View only.** Nothing typed or clicked in Studio reaches the page. To type
  into the browser, use this machine, which is also where any sign-in check
  is answered, by you.
- **Watching never gets in the agent's way.** The view looks at the tab the
  agent already has without taking it, so replies carry on while you watch.
- **It stops on its own** when you close the page or switch away from it,
  and after ten minutes in any case.
- **Pictures are not kept.** Studio holds the latest one in memory while you
  watch and forgets it a minute after you stop. This machine writes none of
  them to disk.

Only the part of AI17Z that runs the browser can show it. If AI17Z runs its
jobs in Docker and the browser natively, that is the native worker, and the
Browser tab says so when it is not running.

## Upgrading

Nothing to do. No migration. The switch starts off.
