AI17Z is a local-first platform for running autonomous agents on your own machine. An agent is an identity, a memory, a model, a policy, and a set of channels it can act on.

## A model id is an identifier again

The agent page showed the same model two ways at once. In the summary at the top it read `Model  Deepseek-v4-pro`; in the Intelligence section directly below it read `deepseek-v4-pro`.

The summary was capitalising the first letter of every value it displayed, and one of those values is the model id. `Deepseek-v4-pro` is not the string DeepSeek answers to, so copying it out of the interface into a config file gets you a 404 from a screen that looked right.

The setup wizard had the same bug and was fixed before Beta 8; nothing pinned the behaviour, so the identical defect survived one screen over. Both screens are now held to it by a test.

Everything else in Beta 8 is unchanged. If you are already on Beta 8 this is a small correction, not a new set of features.

## Everything from Beta 1.0.0 (8)

**Stopping one installation stopped all of them.** With two copies installed, "Stop AI17Z" on either stopped the other's browser worker as well — and with it the real Chrome holding your signed-in X session.

**Setting an agent up leaves you with one that can run.** The model is saved when you press Continue, the review screen reads the agent rather than your unsaved answers, and reconnecting a provider updates it instead of failing.

**Review before action means the action happens.** Advanced setup started agents in review mode *and* turned dry run on, so approving a held reply sent nothing.

**Around thirty settings the runtime already enforced can now be reached from a screen**, in eight labelled groups rather than one flat wall.

**A reply no longer arrives missing its first characters** when X opens its dialog over the inline composer.

## Updating

Nothing updates itself. AI17Z asks GitHub what has been released at most once every six hours, shows you the notes, and offers a link. You can ignore it, skip a version permanently, or turn the check off entirely.

Run this installer over the top of an earlier one. Your agents, memories, provider keys and settings live in your data folder and are not touched. The first start after an upgrade rebuilds and says so.
