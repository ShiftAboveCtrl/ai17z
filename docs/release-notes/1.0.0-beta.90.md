Your coding assistant can now hand finished, public work to the AI17Z agent that talks about your project.

## Development updates, with you in control

Connect a project through the new MCP server, HTTP API or owner command line. The assistant submits the facts and
why they matter. You can review each proposed post, or allow automatic updates within a daily limit and minimum
spacing. New projects start in draft mode with rehearsal enabled, so you can check the whole flow before allowing
anything to publish.

Sender tokens belong to one project and cannot approve posts or change your settings. Submissions containing
credentials, private details, code, security disclosures or unreleased work are refused before their words are
stored. Approved posts pass through the agent's existing policy and publishing checks, with another check at the
moment of sending. An uncertain send is held for investigation rather than risk posting it twice.

This release provides the MCP, API and command line flow, with a dedicated web screen.
See the [development updates guide](https://github.com/ShiftAboveCtrl/ai17z/blob/main/docs/architecture/DEV_UPDATES.md)
for setup, rehearsal and approval commands.

Also included since beta.87: installers and updates fetch from GitHub first, with AI17Z Code as the fallback, and
the dependency update to zod 4.6.7.

Beta.88 and beta.89 were tagged but never released. Beta 0.90 carries their changes and fixes the Ubuntu package dependency declaration for the bundled Python mirror tools.

## Upgrading

Migration 0113 adds the development update tables. Existing projects and posting settings keep their current
behaviour. Development updates stay in rehearsal until you explicitly turn it off for a project.

### Connect your coding assistant

A dedicated screen now connects a project to an agent, issues a scoped token
and provides the MCP connection command. Review and edit development update
drafts, choose their cadence and see what was posted from the app. Real posting
still requires the project's rehearsal switch and the agent's policy to allow it.

### Releases and updates

This release is called **Beta 0.90** and keeps the semver tag
`v1.0.0-beta.89`. GitHub Actions builds and verifies all five native platform
packages. AI17Z Code remains a download backup with the same release files.
