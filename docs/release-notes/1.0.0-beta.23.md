**Beta 3.2 went onto a real installation and the agent was switched on for the first time.** Everything in this release came out of watching what it actually did in the ten minutes that followed. None of it was visible from any test.

---

## Connecting a project no longer floods your agent with its history

Point an agent at a repository and the first poll fetches everything the forge will hand over — twenty releases, twenty commits, whatever is open. All of it is recorded in the same second, so all of it counts as having just happened.

The live agent's first thought was therefore about twenty release tags at once. Its top ten were *Beta 1.0.0 (17)*, *(19)*, *(20)*, *Beta 3.1*, *Beta 3.2* — each scoring nearly the same, each crowding out whatever was actually going on. That is the changelog bot the feature was designed not to be, arriving through a door the design did not cover.

**A repository's existing history is not news.** The first poll is now recorded as backfill: the events are all still there and you still see the whole history on the screen, but your agent is not told about them as things that just happened. Connecting a repository today is not a reason to have opinions about a release from last week.

**An agent that starts watching your project today starts from today.** Anything that happens after that first look reaches it normally, within the quarter of an hour.

## When your agent's thinking fails, it now says so

That same first wake, reflection ran, failed, and recorded two zeros — indistinguishable on screen from a reflection that correctly found nothing to say.

The reason had been worked out and thrown away. The only trace was a debug log line, below the level anything runs at. Finding out what had happened took a direct probe against the database, which is not something anybody running AI17Z should have to do.

The reason is now kept, shown in the Thinking view under the run it belongs to, and an unexpected failure is logged where you will see it.

**A quiet wake still says nothing**, deliberately. Most times an agent looks it finds nothing, the line already says so, and a screen that added *"did not get that far"* to every one of those would be a screen nobody reads.

This is the third time a failure has hidden behind a correct-looking quiet result in this project. The X reader spent an entire release reporting that X had exposed nothing while actually crashing on every attempt.

## An agent that goes and finds out

An agent that keeps a list of things it does not understand and never looks any of them up is not curious — it is uncertain, which is where it started.

An open question or curiosity on its mind can now be looked up, through the same research the agent already uses when somebody asks it something current: the open web through the browser it is already running, and market data for a contract address or ticker.

**Only a question, never a subject.** An interest is a topic, and sending a topic to a search engine returns whatever is being said about it today — which is how a working set fills up with the news.

**What comes back is evidence, and the question stays open.** Nothing marks a question answered because a search returned something. A wrong result reads exactly like a right one, and deciding that a question is settled is a judgement, not a lookup. Confidence moves a little; the rest is for the agent's next proper think.

**One lookup at a time, and not the same one twice.** A question just looked into is left alone for a day whether or not anything came back. A question nothing can answer is not a question to ask again in fifteen minutes.

**It happens where the browser is.** Pressing "think now" does everything else and tells you it looked nothing up, rather than quietly doing less than it says.

## A price call is financial advice

The origination gate from Beta 3.2 was measured against real output: every one of the sixty-eight posts and replies the live agent had actually published. Exactly one matched, and it was a reply saying it does not give financial advice — which the gate does not touch, because it only governs what an agent raises by itself.

That check also showed what was missing. Telling somebody to buy or sell was covered; a price target was not, and a price target is financial advice however it is phrased.

**Ordinary crypto vocabulary stays out of it, on purpose.** An agent connected to market data is meant to talk about tokens. *10x*, *guaranteed*, *pump* and *dyor* are ordinary words in that conversation — *"guaranteed by the unique index"* is a sentence from AI17Z's own documentation. An agent that cannot discuss its own subject gets switched off, which protects nobody.
