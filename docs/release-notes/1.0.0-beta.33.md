**The agent was choosing its tools from its own biography.** One fix, found by watching Beta 4.2 answer a question on a real installation rather than in a test.

## It picks a tool for the question, not for itself

Beta 4.2 narrowed the list of capabilities an agent is shown, because seventy-three of them were too many to be useful. That worked. What it judged the list against did not.

The shortlist was built from the question **and the system layer underneath it**. In a test that layer is a sentence and it changes nothing. On a real reply it is the whole assembled persona: measured here at 3,767 characters against a fifty-character question, listing every subject the agent writes about. So the question was a rounding error, and the menu was chosen from the agent's interests, which are identical for every message it will ever receive.

Asked "what time is it where you are right now, actually", an agent on Beta 4.2 was offered eight repository, contract and market reads, no clock, and answered "I couldn't check the current time". That is exactly the failure narrowing the list was built to remove, reappearing one layer above it.

The menu now comes from what was asked and nothing else. The model still has the whole prompt when it decides; this only chooses what goes on the list.

The same installation, asked the same question afterwards, reads the clock.

## Smaller things

**Asking what its browser is doing already worked**, and still does: it reads its own diagnostics and answers from them, including naming which of its searches are failing.
