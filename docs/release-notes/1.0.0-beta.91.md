Beta 0.91 brings clearer agent activity, more ways to connect accounts, and new tools for shaping an agent's voice.

## See what your agent is doing

Signal Radar now shows receipts for activity and links to its sources. Agents can connect a public home through Studio, and the activity tape makes recent work easier to inspect.

## Shape voice and connect accounts

Trader DNA and voice installation tools help configure an agent's public voice. This release also adds Bluesky connection support and expands the channel adapters, alongside improvements to account setup, memory inspection and policy controls.

## Paper trading and reliability

Paper routing gains a fallback path. The batch also includes fixes to development update setup, worker polling and packaging, and strengthens the privacy checks used before release publication.

## Upgrading

Use the updater belonging to the installation you want to update. Beta 0.91 uses the semver tag `v1.0.0-beta.91`. GitHub Actions builds the Windows, Ubuntu and macOS packages and verifies the published release files.
