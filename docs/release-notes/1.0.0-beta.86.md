`v1.0.0-beta.86` is the first AI17Z published from
[AI17Z Code](https://code.ai17z.io/AI17Z/ai17z), the project's own home, and the
first release since `v1.0.0-beta.76`. Everything built in between (taking
control of an agent's browser, Solana swaps and holdings, real trades approved
on your own machine, trading mandates, protective exits and wallet recovery) is
in it, and each is described in the notes for the version that built it.

`v1.0.0-beta.85` was tagged and never published: its build stopped before
anything was released, and a tag is never moved, so this is the same software
under the next number. The notes below were written for it and apply unchanged.

## AI17Z lives on AI17Z Code

The source, the releases, the issues and the install command now live at
[code.ai17z.io](https://code.ai17z.io/AI17Z/ai17z), a code host AI17Z runs
itself. Reading, cloning and downloading need no account. The install command
is:

```powershell
irm https://code.ai17z.io/AI17Z/ai17z/raw/branch/main/install.ps1 | iex
```

This is not a cosmetic move. In October GitHub restricted the account AI17Z
was published under, and for weeks every install command and every update
check answered "not found". A project whose existence depends on somebody
else's account can be switched off by that somebody, so AI17Z now publishes
from a host it owns. GitHub and GitLab may carry copies; neither is needed to
install, update, read or build AI17Z.

**An installation from an earlier release looks for updates on GitHub.** GitHub
answers again, and this release is copied there as well, so such an
installation can find it the usual way. If it does not, update it once with the
command above (it finds and updates the installation that is already there), or
with that installation's own `update-ai17z.ps1 -Package` pointed at this
release's `AI17Z-App-1.0.0-beta.86.zip`. From this version on, updates are found
on AI17Z Code, and GitHub is not needed.

Everything an installation keeps (agents, memories, credentials, the signed-in
browser) is untouched by the move.

## Downloads come from one place

Every installer and updater downloads only from `code.ai17z.io`, which serves a
release's files itself. An address that does not start there is refused, and
every file is still checked against the release's own `SHA256SUMS.txt` before
anything is written.

## Provenance you can check

Every published file carries a Sigstore bundle, `<file>.sigstore.json`, signed
with AI17Z's release key and recorded in Sigstore's public transparency log. The
public half of the key is
[`.forgejo/cosign.pub`](https://code.ai17z.io/AI17Z/ai17z/src/branch/main/.forgejo/cosign.pub)
in the repository. Checking is optional, needs `cosign`, and is described in
[MACOS_TRUST.md](https://code.ai17z.io/AI17Z/ai17z/src/branch/main/docs/MACOS_TRUST.md).
It is release provenance, not a signature from Apple, Microsoft or Canonical;
AI17Z is still not code-signed, and says so.

## Every Mac, and arm64 Ubuntu, without a machine of each

AI17Z Code has no Mac and no arm64 Linux machine, and this release still
carries packages for Apple silicon Macs, Intel Macs and arm64 Ubuntu. Each is
assembled on Linux from exactly the files that machine would have installed:
Node's own build for it from nodejs.org and the prebuilt packages npm
publishes for it. AI17Z compiles nothing, so there is no step that machine
would have done differently, and that is checked rather than assumed: every
native file in each package is byte for byte the one in a package a real
machine of that kind built and tested (v1.0.0-beta.76, built on GitHub's
hosted Macs and arm64 runner), or the package is refused.

A release that needs a native file no such machine has built yet goes out
without that package and says so, and the installers and updaters on that
machine take the newest release that has one, rather than stopping.

Intel Macs are back for that reason: nothing in their package is relabelled.

## Also in this release

- **A pool's price history can be read a page at a time.** `market.ohlcv`
  takes an optional `before`, so a history longer than a hundred candles is
  read in pages, and the cache keeps each page apart instead of answering every
  page with the first.
- **Who holds a Solana token.** `solana.read_token_holders` reads a mint's
  largest holders, each share of the supply exactly, and whether each owner
  looks like a wallet or a program such as a pool or launchpad, with how
  concentrated the supply is either way. The classification is a heuristic and
  says so.
- **A wake records how long it took on the wall clock.** It used to measure
  from the moment it reasoned about, which a caller can set; a test pinned to
  September overflowed the column on 20 October.
