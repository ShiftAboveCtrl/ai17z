**Beta 3.8, published.** Its release could not finish because one of its own tests was reaching for a browser, so nothing shipped. Nothing about AI17Z changed between the two; this is the same release with that test fixed.

Everything in Beta 3.5, 3.6 and 3.7 is here too, and Beta 3.8's notes describe the fix that matters: an agent's own like was being carried out twice, and the ledger that exists to stop that keyed on how the target was spelled rather than on which post it was.

## What went wrong with 3.8

The test that proves an agent's own like leaves a record rather than work for the queue was written against a real X account, and acting on one opens a browser and goes to x.com.

On the machine it was written on that fails in five seconds, because no browser session is configured for a test account. On the machine that builds a release it does not fail: the build installs a browser before it runs the suite. So a suite that was green in one place was red in the other, and the release stopped at its own gate, which is exactly what that gate is for.

The test now uses the mock channel. It exercises the same path and stops at the adapter, which is all it ever needed to do.
