`v1.0.0-beta.82` lets a Studio trading agent ask your own AI17Z for a real trade, which you approve here.

## Real trades from Studio

A trading agent on AI17Z Studio decides, and Studio holds no key. With
**Real trades from Studio** turned on in the Studio panel, this installation
collects what a Studio agent asks for, prepares each trade here and waits for
you:

- **Off until you turn it on**, and separate from control from Studio.
- **Carried out by an agent you choose here.** Its mandate, wallet and limits
  apply, through the same path as a trade you start yourself. A Studio agent
  nobody chose is refused, with a sentence.
- **Approved here, by the exact transaction.** Review builds it again, because a
  Solana transaction is good for about a minute, and Approve and send approves
  exactly what you were shown and sends it at once. The mandate and the pause
  are read again at that moment.
- **Once.** A request delivered twice is one trade, and a sent trade is checked
  by its hash, never sent again.
- **You are told.** A trade waiting for you is a notification, on Telegram too
  if it is paired, and clears when it is approved, rejected or expires.
- **Studio hears every step**, from prepared to confirmed, and only ever
  forward.

## A wallet adapter in an installed copy

An installed AI17Z runs its API and jobs worker in containers, which could not
see a wallet adapter on your disk, so an installed copy could not sign anything.
Set `AI17Z_WALLET_ADAPTER_DIR` to the directory you installed the adapter in, and
`AI17Z_WALLET_ADAPTER_SHA256` to the hash of its `index.mjs`: it is mounted
read-only into both and held to that hash. Unset, nothing is mounted and nothing
is created beside the program.

## One way to send a trade

A transaction that carries a live trade can no longer be approved or sent from
the plain wallet screen, which would have skipped the trade's own checks at the
moment of sending. Approve it from the trade.

## The address AI17Z tells you to open

AI17Z listens on `127.0.0.1`, and now says so: the start, diagnostics and setup
scripts print that address rather than `localhost`, which some machines
resolve to `::1` first.

## Upgrading

Nothing to do. No migration. Real trades from Studio stay off until you turn
them on.
