# Linking within the existing AI17Z interface

This bounded change follows the Plugins screen's existing dark surfaces, bone text, rounded panels, typography and spacing. The domain is local agent software. Owners need a clear benefit, one next action and precise permission boundaries.

The Studio panel starts with one benefit sentence, then offers the public Studio directly on a fresh installation. A pending link makes the prefilled approval link the primary action, keeps the manual code visible for another device, and explains the return to the local tab. Primary linking targets are at least 48 pixels tall. Existing focus, loading, disabled and error states remain in use. No new imagery, motion or visual identity is introduced.

Control, live view and takeover remain separate switches that start off. Never imply that linking shares agents or enables those switches. Match Studio's existing design for the other half of the journey.
